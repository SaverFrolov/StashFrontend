1. О ПРОЕКТЕ
--------------------------------------------------------------------------------
Stash (первоначально «Inbox», переименован 13.11.2026 по выбору пользователя) —
фронтенд «универсального личного входящего ящика», реализованный строго по
спецификации frontend_v2.docx.

Суть продукта: сохранять ссылки, текстовые заметки, файлы (PDF, DOCX, таблицы
Excel), аудио (записи с микрофона и MP3) и видео из браузера, с компьютера или
телефона в одно хранилище. Система сохраняет оригинал, извлекает текст, а
ИИ-модель добавляет аннотацию и теги. Интерфейс захватывает, организует и
находит — это не чат-бот.

Бэкенд вне объёма работ: приложение общается с API через интерфейс ApiClient.
По умолчанию используется полнофункциональный MockApi (localStorage, задержки
300–900 мс, живой конвейер обработки saved → extracting → annotating → done с
симуляцией сбоев). При указании VITE_API_BASE_URL автоматически включается
RestApi (Bearer-авторизация, JSON-эндпоинты) — переключение без правок кода.

2. АРХИТЕКТУРА (pnpm-монорепозиторий)
--------------------------------------------------------------------------------
apps/web            — веб-приложение / PWA: React 18 + Vite 5 + TypeScript
                      (strict) + Tailwind 3.4 + Radix UI + TanStack Query v5 +
                      react-i18next + react-router-dom v6 + Zod
apps/extension      — Chromium MV3 расширение (popup, options, контекстные меню)
packages/ui         — дизайн-токены (CSS-переменные), Tailwind-пресет,
                      компоненты на Radix (Button, Field, Dialog, Menu, Toast,
                      SegmentedControl, StatusChip, TagChip и др.)
packages/api-client — типы, Zod-схемы, интерфейс ApiClient, MockApi, RestApi,
                      демо-данные (19 элементов, 3 коллекции, ~12 тегов)
scripts/gen-icons.mjs — генератор PNG-иконок без внешних зависимостей
docs/design-tokens.md — справочник дизайн-токенов

3. ЭКРАНЫ (S1–S12 по спецификации)
--------------------------------------------------------------------------------
S1  /login           — вход (MockApi принимает любые учётные данные)
S2  /signup          — регистрация с валидацией
S3  /reset-password  — сброс пароля, состояние «проверьте почту»
S4  /inbox           — лента «как в мессенджере»: новые снизу, разделители дат,
                       infinite scroll, сегмент-фильтры (Все / Требуют внимания /
                       Ссылки / Заметки / Файлы / Аудио), композер внизу
S5  /items/:id       — детали элемента: 4 слоя раздельно (Оригинал / Мой
                       комментарий / Аннотация ИИ / Извлечённый текст), метка
                       «ИИ» и предупреждение «Создано ИИ. Сверяйте с
                       оригиналом.», восстановление ИИ-версии, теги, коллекции,
                       похожий контент, детали обработки; на экранах ≥1280px —
                       сплит «лента 480px + панель деталей»
S6  /search          — режимы «умный / ключевые слова / смысл», подсветка <mark>,
                       бейджи совпадений, фильтры (тип, коллекция, тег, даты,
                       статус), недавние запросы
S7  /collections     — список коллекций со счётчиками элементов
S8  /collections/:id — содержимое коллекции, сортировки, удаление из коллекции
S9  /tags            — таблица тегов: переименование, объединение, удаление,
                       счётчики, происхождение (пользователь / ИИ)
S10 /settings        — 6 разделов: Аккаунт (включая удаление с вводом почты),
                       Внешний вид и язык, Обработка ИИ (провайдер, Base URL,
                       модель, API-ключ write-only, тест подключения),
                       Захват (расширение, телефон/PWA, API-токены), Данные
                       (экспорт, занятое место), О программе
S11 /capture         — полноэкранный быстрый захват для телефона + Web Share
                       Target (приём ссылок/текста/файлов из меню «Поделиться»)
S12 системные        — 404, offline-состояние, ErrorBoundary («Something broke»
                       с кнопкой Reload)

4. МОДАЛЬНЫЕ ОКНА (M1–M14)
--------------------------------------------------------------------------------
M1 загрузка файлов (drag&drop на любую точку ленты), M2 добавление в коллекцию
(поиск + создание на лету), M3 форма коллекции, M4 комбобокс тегов с
автодополнением, M5 переименование/объединение тегов, M6 подтверждение
удаления (аккаунт — с вводом почты), M7 экспорт (область, формат JSON/Markdown,
набор включаемых данных, прогресс), M8 drawer деталей обработки (шаги,
timestamps, ошибки, Retry), M9 подтверждение переработки (что заменится / что
не тронется), M10 отказ микрофона / неподдерживаемый браузер, M11 командная
палитра (⌘K/Ctrl+K, топ-6 результатов, стрелки+Enter), M12 API-токены
(reveal-once), M13 истёкшая сессия (вход без потери черновиков), M14 шпаргалка
горячих клавиш («?»)

5. КОМПОНЕНТ КОМПОЗЕРА И ЗАПИСИ АУДИО
--------------------------------------------------------------------------------
— autosize-textarea; Enter — отправить, Shift+Enter — новая строка
— один URL во вводе → сохранение как ссылка (чип с доменом); иначе заметка
— скрепка → диалог загрузки; микрофон превращается в Send при наборе текста
— рекордер на MediaRecorder: live level bar (AnalyserNode), Pause/Resume,
 elapsed time (tabular-nums), Discard, Stop → встроенный плеер + Send/Discard
— черновики сохраняются в localStorage; offline-баннер; аудио без транскрипции
 завершается статусом «Не полностью» (как в спецификации)

6. ФОРМАТЫ ФАЙЛОВ (расширение от 14.11.2026)
--------------------------------------------------------------------------------
Поддерживаются: PDF, DOCX, аудио (MP3, WAV, OGG, M4A, FLAC, AAC), видео (MP4,
WEBM, MOV, M4V, MKV), таблицы Excel (XLSX, XLS).
— Ограничение по размеру файла УБРАНО по запросу пользователя (14.11.2026)
— Тип определяется по mime с откатом на расширение (typeFromMime, покрыт
 юнитами)
— Иконки типов: Video и Sheet в карточках и командной палитре
— Видеоплеер в деталях элемента; аудио-плеер для записей и MP3
— Загруженное аудио ведёт себя как голосовые заметки (статус «Не полностью»)
— Фильтр «Файлы» охватывает pdf/docx/xlsx/video
— PWA share target принимает видео, аудио и Excel

7. ДИЗАЙН: LIQUID GLASS (редизайн 14.11.2026 по запросу пользователя)
--------------------------------------------------------------------------------
— Полупрозрачные «стеклянные» панели с backdrop-filter: blur(20px) +
 saturate(160%); правило применяется глобально к .bg-surface
— Фон-аура: фиксированные зелёные радиальные градиенты на body и .bg-bg
— Зелёный акцент сохранён (продуктовая идентичность): #0E7C66 (светлая) /
 #3FB59B (тёмная); основные кнопки — градиент + зелёное свечение (shadow-glow)
— Радиусы увеличены: 10px контролы, 18px диалоги/панели
— Итерации по отзывам пользователя:
  * убраны белые specular-линии (inset-подсветка glass-rim)
  * все hairline-границы переведены на зеленоватые оттенки
  * поверхности переведены с белой полупрозрачности на зеленоватую
  * чипы дат, строки поиска, «⋯»-меню карточек, выпадающие меню и командная
   палитра получили яркую зелёную обводку (border-accent/40)
  * карточки материалов скруглены (14px) и отделены отступами
  * в свёрнутом сайдбаре название скрыто полностью (без буквы «S»)
  * белый цвет удалён везде, кроме текста на зелёных кнопках
— Три темы: light / dark / system (prefers-color-scheme)
— WCAG AA: статусы только «иконка + текст» (никогда не цвет alone), фокус-кольцо
 2px accent, prefers-reduced-motion отключает анимации, тач-цели ≥44px

8. КОМПАКТНЫЙ ФИЛЬТР-БАР (по детальной спецификации пользователя)
--------------------------------------------------------------------------------
— При прокрутке ленты фильтр-бар сворачивается и докуется в шапку справа;
 поиск остаётся слева без изменения ширины
— Один и тот же DOM-узел в обоих состояниях (без reparenting — фокус и порядок
 табуляции сохраняются); перемещение чисто на CSS (fixed)
— Состояние: data-condensed на шапке, общий контекст CondensedProvider
— Триггер: IntersectionObserver на сентинеле у «живого края» ленты (лента
 инвертирована), гистерезис 80px вход / 24px выход через пересоздание
 наблюдателя; никаких scroll-листенеров; iOS overscroll не переключает
— Анимация: View Transitions API (морф 220мс ease-out, только композитор) с
 feature detection и мгновенным фолбэком; первая оценка — без вспышки
— Без layout shift: плейсхолдер резервирует измеренную высоту бара
 (ResizeObserver); scrollY не меняется; петли «скролл→высота→скролл» нет
— Компактный вид: ниже, плотнее отступы, цели нажатия ≥32px, горизонтальный
 скролл со скрытым скроллбаром и fade-масками по краям
— <1024px: отдельная компактная sticky-строка (док только там, где есть
 десктопная шапка); 1024–1279px: строка поиска уступает место бару
— Оболочка зафиксирована по высоте вьюпорта (h-dvh overflow-hidden): шапка и
 бар не прокручиваются вместе с окном; экраны имеют собственные
 скролл-контейнеры; --header-h без магических чисел

генератор PNG без зависимостей), service worker, баннер установки (dismissable,

Расширение (Chromium MV3):

— загрузка unpacked: apps/extension/dist; работает в Chrome, Edge, Яндекс
 Браузере и Opera

11. КРОСС-БРАУЗЕРНЫЙ АУДИТ (14–16.11.2026)
--------------------------------------------------------------------------------
Критическая находка: Tailwind 3 не применяет модификаторы прозрачности (/40,
/10) к цветам-строкам var() — классы border-accent/40 и др. НЕ генерировались,
и элементы получали дефолтную серую рамку Tailwind (#e5e7eb) — это и были
«белые полосы», которые пользователь видел несколько итераций. Исправлено
переводом цветов на канальный формат rgb(var(--x-rgb) / <alpha-value>) +
RGB-каналы во всех трёх темах; верифицировано grep'ом собранного CSS.

Фолбэки: structuredClone → JSON (Safari <15.4), 100vh перед каждым 100dvh
(Safari <15.4, Chrome <108), webkitAudioContext (Safari <14.1),
navigator.clipboard? (non-secure contexts), View Transitions / MediaRecorder /
beforeinstallprompt — feature detection.

Совместимость: Chrome/Edge/Яндекс Браузер/Opera — полностью (включая PWA и
расширение); Firefox — полностью (PWA через «Добавить на главный экран», без
расширения); Safari macOS/iOS — полностью (PWA через «Добавить на главный
экран»). Базовый уровень сборки — ES2020 (Chrome 87+, Safari 14+, FF 78+).

12. ИСПРАВЛЕННЫЕ БАГИ
--------------------------------------------------------------------------------
— Стартовый краш «Something broke»: useNavigate() использовался вне <Router>
 (CommandPaletteProvider, SessionExpiredDialog) — BrowserRouter поднят выше
 провайдеров; добавлен jsdom smoke-тест (логин → лента), который и нашёл баг,
 не проявившийся при чистой сборке
— i18n: initImmediate=false + useSuspense=false (защита от suspense-броска
 в ErrorBoundary)
— stateful /g regex в подсветке поиска пропускал <mark>
— «⋯»-меню карточки улетало вправо-вверх: hover-панель скрывалась, триггер
 размонтировался; первый фикс не сработал из-за порядка утилит Tailwind
 (.hidden побеждает .flex) — исправлено полной заменой набора классов
— dev-сервер не подхватывал изменения Tailwind-пресета из линкованного пакета
 — решено перезапуском с очисткой кэша Vite + верификацией dev-CSS curl'ом
— Иконка сворачивания сайдбара «косила вправо» (ml-auto при скрытом названии)
— Подсветка выбранного языка не переносилась с RU на EN (см. раздел 9)
— Пагинация MockApi для ленты с загрузкой «вверх» (курсор = более ранние)
